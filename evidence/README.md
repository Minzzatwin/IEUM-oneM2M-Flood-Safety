# Evidence Directory

This directory is reserved for sanitized evidence that can be legally and safely published with the repository.

Acceptable evidence includes:

- Redacted HTTP response captures.
- Redacted terminal logs.
- Resource-tree screenshots with private identifiers removed.
- Test dates, commands, and environment labels.

Do not add:

- Credentials, tokens, passwords, or private endpoints.
- Unredacted Sandbox identifiers or IP addresses.
- Personal information.
- Unverified claims presented as test output.

No raw video file is included in this repository. Historical test results are summarized in [docs/test-results.md](../docs/test-results.md).
